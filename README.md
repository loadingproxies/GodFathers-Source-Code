# GodFathers OCR

Local Idle Mafia helper for the Roblox desktop player. It screenshots the game window, reads text with RapidOCR on this PC, then moves the mouse. There is no account, no server, and none of our code makes HTTP requests.

`app/`, `tests/`, and `tools/` have no `requests`, `urllib`, or URLs. First install uses pip/winget so Python and RapidOCR can land on disk. After that, Start is capture + OCR + clicks.

Double-click `Start GodFathers OCR.bat`. F2 is the live HUD. F3 stops.
